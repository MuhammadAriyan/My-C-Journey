### Logical Operators
1. if
2. if else
3. if else if 


### 1. If

` 
#### syntax
	if(condition){
	do;};

#### example 
	int age = 1;
	if(age < 1){
	printf("Your age is shorter than 1");};
`
####  explanation
if age is less than  ( < ) 1 then print "Your age is shorter than 1"




### 2. if else

` 
#### syntax
	if(condition){
	do;}else{
		do_this_then;
	};

#### example 
	int age = 1;
	if(age < 1){
		printf("Your age is shorter than 1");}
		else{
		printf("your age is more than 1");
	};
`
####  explanation
if age is less than  ( < ) 1 then print "Your age is shorter than 1"
else print age is more than 1



### 3. if else if

` 
#### syntax
	if(condition){
	do;};

#### example 
	int age = 1;
	if(age < 1){
	printf("Your age is shorter than 1");}
	else if( age = 18 ){
		printf("your age is 18");
	};
`
####  explanation
if age is less than  ( < ) 1 then print "Your age is shorter than 1"
but if age is 18 then print "your age is 18"
